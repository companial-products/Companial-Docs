# Funções indisponíveis em outros idiomas

Devido a um erro de tradução, alguns perfis estavam aparecendo indevidamente na lista de perfis em português.

Ao utilizar o campo de **Função**, dentro de **Minhas Configurações**, no BC, as funções abaixo estão com erro na tradução para o Português:

| Financeiro |
| --- |
| Recursos Humanos |
| Produção |
| Projeto |
| Compras |
| Recurso |
| Vendas e Marketing |
| Serviço |
| Armazém |

Para que elas apareçam em outros idiomas, basta acessar **Perfis (Funções)**, pesquisar a função que deseja, e mudar o campo de **Descrição**.

Depois disso, a função poderá ser acessada em qualquer idioma.

A correção poderá ocorrer eventualmente, caso o usuário realmente queira usar o perfil "em branco", deve acessar a tela para mudar a descrição.
